# THE MISSION

Интерактивный прототип Telegram Mini App по чистовым макетам Figma.

## Запуск

Требуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Открыть адрес, который покажет Vite. Главная открывается сразу; вход и регистрация доступны по `/?screen=464%3A1674`.

Каталог всех экранов: `/?catalog=1`. Статичный вид телефона для сравнения с Figma: `/?frame=1&screen=457%3A5863`.

## Что перенесено

127 экранов получены из точного контекста Figma и представлены редактируемыми React-элементами с обычным CSS. Сохранены исходные фотографии, SVG-иконки, цвета, начертания и ссылки на узлы Figma. Ассеты и шрифты лежат локально; временных URL Figma в исполняемом коде нет.

12 дополнительных состояний используют общие шаблоны: на них сработал лимит Figma MCP. Они отмечены в каталоге и перечислены в `docs/port-coverage.json`. Их нельзя считать проверенными на точное совпадение с макетом.

Работают основные переходы, редактирование полей, согласия, знакомство и его принятие, независимая отправка рекомендации, сохранение участников, поиск и фильтры, локальные запросы и демонстрационные состояния сделок. Данные хранятся в браузере. Очистка данных сайта сбрасывает демонстрацию.

Внутри Telegram используются его системная оболочка и кнопка возврата. В обычном режиме страницы нарисованная шапка Telegram скрыта; `frame=1` предназначен только для сравнения с макетом вне Telegram.

Между основными разделами — мягкое появление за 200 мс, внутри разделов — сдвиг за 260 мс с обратным направлением при возврате. Следующий экран загружается до переключения. При системной настройке уменьшения движения и в режиме сравнения с макетом анимация отключена.

## Границы прототипа

Оплата, ИИ, модерация, приглашения и отправка сообщений не обращаются к настоящему серверу. Кнопки внешней отправки показывают уведомление об имитации. Для запуска внутри Telegram понадобятся опубликованный HTTPS-адрес и настройка бота; публикация в этом репозитории автоматически не выполняется.

Карточки и профили используют небольшое количество примеров. Для Андрея Белова и Марии Волковой созданы отдельные вымышленные биографии, компании, запросы и экспертизы. Имя, фотография и выбранный участник сохраняются при переходах между вкладками и перезагрузке. Профиль Александра заполнен текстом из предоставленного пользователем документа.

## Проверка

```sh
npm test
npm run build
```

При работающем `npm run dev -- --port 5173` и установленном Chromium Playwright:

```sh
npx playwright install chromium
node scripts/interaction-check.mjs
node scripts/records-check.mjs
node scripts/extended-check.mjs
node scripts/motion-check.mjs
node scripts/back-check.mjs
node scripts/composer-check.mjs
node scripts/profile-check.mjs
node scripts/participant-check.mjs
node scripts/screen-check.mjs
```

Проверки покрывают независимость рекомендации и знакомства, повторную отправку, согласия, локальные записи, загрузку всех 139 экранов (включая 12 временных состояний) и их изображений, направление анимации и уменьшение движения. Ширины проверки: 320, 360, 393 и 430. Проверка загрузки не является утверждением о ручной визуальной сверке каждого экрана.

## Структура

- `src/design/screens/` — визуальные экраны с исходными идентификаторами Figma.
- `src/design/generated.css` — общие CSS-правила, без зависимости от Tailwind.
- `src/design/behavior.json` — переходы, извлечённые из Figma.
- `src/prototype/` — Telegram, состояние, интерактивные адаптеры и временные шаблоны.
- `public/assets/` — оригинальные изображения и SVG, одинаковые файлы объединены по SHA-256.
- `public/fonts/` — локальные Onest и IBM Plex Mono с лицензиями.
- `docs/FIGMA_HANDOFF.md` — карта переноса и канонические экраны.

Визуальные экраны загружаются отдельными частями по мере перехода. Скрипты импорта требуют локальных ответов Figma в `.design-reference/`; они не нужны для запуска или сборки уже сохранённой версии.
