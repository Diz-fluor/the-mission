Входы добавляются в ленту запросов, «Мои», ручное создание, редактирование и пустое состояние. Ручное создание остаётся самостоятельным путём. При выходе из помощника исходная форма не меняется; «Заполнить вручную» явно переносит подготовленный текст.

Сессия сохраняется в общем браузерном состоянии в поле `ai-request-session`. Сохранённые черновики и опубликованные запросы используют один массив `requests`; статус `draft` исключается из общей ленты. Публикация и повторное сохранение обновляют запись с тем же идентификатором. Закрытие использует существующий путь приложения. Ручные изменения заголовка и описания сохраняются при повторной подготовке.

Новый UI использует React и обычный CSS, локальные ассеты Figma и существующие адаптеры основной кнопки «Связь», зелёного стекла и входа ИИ. Экран имеет отдельную прокручиваемую область, закреплённое основное действие и нативные поля, радио и списки. Ширины проверки: 320, 360, 393, 430. Режим `?frame=1&screen=838%3A7580` предназначен для сверки с Figma.

## Демонстрационный провайдер

Настоящий ИИ и сервер не подключены. `generateDemoRequest` явно обозначен как локальная демонстрация, возвращает только заголовок и описание на основе введённого текста и явно выбранного результата. Он не придумывает цену, срок, формат, людей или факты. Демо-подбор использует существующих участников; неподходящие запросы ведут в пустое состояние, а не к произвольным людям. Текст запроса передаётся в существующий экран подбора.

Для реального сервиса следует заменить провайдер серверным вызовом с `AbortSignal`, валидировать ответ и хранить ключи на сервере. Публикация должна остаться отдельным действием после проверки. Локальные задержки и показ демонстрации не являются работающей интеграцией с моделью.

## Проверки

- `npm test`: модель помощника и общее состояние.
- `npm run build`: TypeScript и production-сборка.
- `node scripts/ai-request-check.mjs`: полный сценарий, возвраты, повторная генерация, приватность черновика, перезагрузка, отсутствие дублей, закрытие, подбор, отмена, ручное создание, ошибка, локальные изображения и четыре ширины.
- `node scripts/records-check.mjs`: прежнее создание/редактирование/закрытие запросов и идемпотентное подтверждение взноса.

Новые макеты перенесены в код с нативными контролами; исходные статические экраны остальных разделов не перегенерировались.
