# Telegram prototype Implementation Plan

**Goal:** Перенести чистовые макеты THE MISSION в интерактивный локальный прототип Telegram Mini App.

**Architecture:** React и TypeScript, CSS из параметров Figma. Локальные ассеты, общий адаптер Telegram, маршруты и демонстрационное состояние отдельно от визуальных экранов. Системная оболочка не дублируется внутри Telegram.

**Spec:** docs/FIGMA_HANDOFF.md

- [ ] Получить точный контекст всех чистовых экранов: 127 готовы, 12 ожидают снятия лимита Figma. Ассеты скачаны локально.
- [x] Собрать визуальные экраны, общие стили и маршрутизацию.
- [x] Подключить локальные состояния форм, знакомства, рекомендаций, фильтров и сохранения.
- [x] Проверить сборку, основные переходы и отображение на мобильных размерах.
- [ ] Сохранить проверенную версию в GitHub и описать границы демонстрации.

## Итог проверки 2026-11-07

Сборка и 8 проверок состояния проходят. Пройдены 7 основных браузерных сценариев, создание/изменение/закрытие запроса и проверка суммы поддержки без повторного зачисления. Ранее проверена загрузка всех 127 перенесённых экранов без ошибок JavaScript и изображений; мобильные ширины 320–430 без горизонтального переполнения.

Версия сохранена локально в ветке `codex/telegram-prototype`. Отправка в GitHub заблокирована доступом: локальный HTTPS Git не авторизован, подключённая интеграция возвращает 403 на запись. Запись в main отдельно отклонена автоматической проверкой как выход за согласованную отдельную ветку; main не опубликован. Границы демонстрации описаны в README.

## Review focus

Сохранение статуса человека при переключении вкладок; отдельность знакомства и рекомендации; отсутствие настоящих оплат и отправок; безопасные пустые значения Telegram; локальные изображения вместо временных URL Figma.
